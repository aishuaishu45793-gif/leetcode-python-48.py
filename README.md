## 💻 Sample Python Program

### Check Whether a Number Is Prime

```python
number = 17
is_prime = True

if number < 2:
    is_prime = False
else:
    for i in range(2, int(number ** 0.5) + 1):
        if number % i == 0:
            is_prime = False
            break

if is_prime:
    print(number, "is a prime number")
else:
    print(number, "is not a prime number")
```

**Output:**

```text
17 is a prime number
```
